Red appears only when a person has to do something. Blue appears only as the water line. Everything else is ink on a neutral page, so photos never compete with a tinted background.

Type

Archivo, one family in two widths. Plant names and screen titles: extra-condensed, heavy, like a printed plant tag. Everything else: normal width. Latin names in italic. No all-caps labels, no middle-dot strings.

What changed from the last version

Clay-red alert (a common AI accent) replaced by a cooler raspberry red. The summary pills and the matching section labels merged into one heading. The three identical cards became a sentence, a full-width tank gauge and plain rows. Only photos have rounded corners. Second pass: the gauges moved off the photos; the water level is a blue line under the photo, red only when low.

Apple-design pass: 44 pt tap targets; frosted back and more buttons over the photo; tracking tightened on big names and opened slightly on small text; tabular figures so numbers line up; the same rows in the same order on every plant page; a dashed line for "no reading" so it never looks like an empty tank; a row into the plant's history so the page has a way onward; the paused message says how it resumes.
